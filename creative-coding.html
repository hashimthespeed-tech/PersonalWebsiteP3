Code can be
a material.

I’m interested in the moment a technical skill stops being the point and starts becoming a way to ask better questions.

“The first draft is a place to begin, not a place to live.”

A small manifesto

Make the invisible easier to feel.

Creative coding gives me a way to turn systems into something people can touch. I like interfaces that have a point of view but never make the person using them feel lost.

I use code to build tiny instruments, visual essays, and tools that help people tell stories. The technical challenge is satisfying; the human outcome is what keeps me going.

How I work

Start with a
human question.

Tools are only useful when they help us notice, understand, or connect.

01 · Listen

Find the real question.

Before I open a code editor, I want to understand who this is for and what they already know.

02 · Prototype

Make the smallest version.

A rough, working thing teaches more than a polished idea trapped in a deck.

03 · Invite

Let other people shape it.

The best work has evidence of other people in it.
